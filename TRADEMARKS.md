# Uso do nome "HelpMyDesk"

O código é livre (GPL-3.0-or-later): você pode estudar, modificar e redistribuir. O **nome**
"HelpMyDesk" e o ícone identificam os builds oficiais, assinados pelo projeto.

Como este software executa ações no computador de pessoas leigas, um fork malicioso com o mesmo
nome seria um risco real. Por isso:

- Forks e redistribuições modificadas **devem usar outro nome** e deixar claro que não são o
  HelpMyDesk oficial.
- É permitido citar o nome para descrever a origem ("baseado no HelpMyDesk").
- Canais oficiais: somente
  [GitHub Releases](https://github.com/JamesonHenrique/helpmydesk/releases) e, quando existir,
  o repositório apt documentado no README.
